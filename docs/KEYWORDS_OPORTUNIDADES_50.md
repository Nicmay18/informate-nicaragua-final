## Reglas anti-canibalización

- Una consulta = una URL. Si "citas minrex" y "citas cancillería" compiten, **no** crear página separada: la guía apostillar ya responde ambas (FAQ añadida).
- Las guías nuevas solo se crean con evidencia de demanda (GSC queries, Keyword Planner o cluster probado). No crear páginas doorway.
- Todo contenido nuevo enlaza a la página pilar de su cluster y viceversa.
- Revisar trimestralmente: si una guía no supera 50 impresiones/mes en 90 días, consolidar o mejorarla, no duplicarla.
